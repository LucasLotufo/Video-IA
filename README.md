# Video-IA — laboratório HyperFrames

Projeto de estudos para criar vídeos programaticamente com o [HyperFrames](https://github.com/heygen-com/hyperframes).

## Pré-requisitos
- Git
- Node.js e npm/npx
- Um agente de programação compatível com Skills (por exemplo, Codex)

## Instalação
1. Clone este repositório: `git clone https://github.com/LucasLotufo/Video-IA.git`
2. Entre na pasta: `cd Video-IA`
3. No ambiente do agente compatível, instale a skill HyperFrames: `npx skills add heygen-com/hyperframes`
4. Abra o projeto no agente e peça para criar um vídeo seguindo `exemplos/primeiro-video.md`.
5. Siga as instruções de renderização e dependências fornecidas pela skill.

> Este repositório contém um exemplo de prompt e documentação, não um vídeo MP4 pronto. A instalação da skill ocorre no ambiente local do agente, não diretamente nesta conversa do ChatGPT.
